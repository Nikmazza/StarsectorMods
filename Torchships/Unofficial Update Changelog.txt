			- All modular weapons added by the mod are now able to have their blueprints obtained through the Low Tech blueprint package

			- Firespitter fighter blueprint is in the Low Tech blueprint package
		- Midline blueprint package
			- Blueprints for the Pest, Scalper, Crane, and Hightide are in the Midline blueprint package

		- High Tech blueprint package
			- Blueprint for Cassicus is in the High Tech blueprint package
			- Blueprint for the Pinnace gunship is in the High Tech blueprint package
		- Pirate blueprint package

			- All Luddic Path skin ships besides the Bonnethead Mk.III are in the Luddic Path blueprint package
		- XIV blueprint package
			- Both the Niagara (XIV) and Pest (XIV) are a part of the XIV blueprint package
		- Rare blueprint
			- Note: this means that the blueprint for the ship is not a part of a blueprint package, and can be found as an individual blueprint via exploration in the case of this mod
			- Whirlwind, Herald, Niagara, Niagara (P) Lasher (TT), Bonnethead, Bonnethead Mk.II, Bonnethead Mk.III, Owl, and Attrition have individual blueprints and are not part of a blueprint package

			- Note: its those Historian npcs you can sometimes come across as a bar encounter and can give you some blueprint locations in exchange for story point(s)
